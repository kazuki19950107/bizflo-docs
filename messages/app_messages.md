# アプリ内メッセージテンプレート

---

## 1. 初回ログイン時のウェルカムメッセージ

### メインメッセージ
```
BizFloへようこそ！

まずは初期設定を完了して、すぐに業務管理を始めましょう。
設定は5分程度で完了します。
```

### ステップ案内
```
【セットアップガイド】

① 会社情報を入力する
   → 請求書や帳票に自動反映されます

② チームメンバーを招待する
   → ユーザー管理から招待メールを送信

③ 顧客を登録する
   → 名刺OCRやテキスト解析で簡単に登録

④ 最初の案件を作成する
   → 案件一覧から「案件追加」をクリック
```

---

## 2. 機能紹介Tips（ダッシュボード表示用）

### 顧客管理
```
名刺をアップロードするだけで顧客情報を自動登録できます。
「顧客登録 → 名刺アップロード」から試してみましょう。
```

### AIアシスタント
```
AIアシスタントに自然言語で質問できます。
「今月の売上は？」「来週のスケジュールを教えて」などを試してみてください。
```

### LINE連携
```
LINE連携を設定すると、毎朝9時にスケジュールとタスクのまとめが届きます。
「基本設定 → LINE連携」から設定できます。
```

### 請求書
```
請求書は見積書からワンクリックで作成できます。
ステータスを変更するだけで、見積書→請求書→領収書と切り替わります。
```

### 定期タスク
```
毎週・毎月の定例タスクは「定期タスク」で自動化できます。
タスク作成時に繰り返し設定をONにしてください。
```

### KPI
```
KPIダッシュボードで目標達成率と予測をリアルタイムで確認できます。
「経営管理 → KPI」から設定してみましょう。
```

### 予約管理
```
公開予約フォームを作成すると、顧客が直接Web予約できるようになります。
「予約管理 → スロット設定」から始められます。
```

## 3. 設定完了メッセージ

### 会社情報の設定完了
```
会社情報の設定が完了しました。
入力した情報は請求書・見積書に自動反映されます。
```

### LINE連携の設定完了
```
LINE連携の設定が完了しました。
明日の朝9時からモーニングメモが届きます。
通知の曜日は「ユーザー設定」から変更できます。
```

### Google Calendar連携の設定完了
```
Google Calendarとの連携が完了しました。
Googleカレンダーの予定がBizFloのカレンダーに表示されます。
```

## 4. 通知メッセージ

### リリースノート通知
```
BizFloがアップデートされました。

{バージョン}: {タイトル}

詳細はリリースノートをご確認ください。
```

### 共有リンクへのアクセス通知
```
{案件名} の共有リンクにアクセスがありました。

アクセス日時: {日時}
共有リンクの管理は案件詳細画面から確認できます。
```

### 支払期日のリマインダー
```
支払期日が近づいている請求書があります。

{顧客名} - {件名}
金額: {金額}円
支払期日: {日付}

請求書一覧から詳細を確認してください。
```

## 5. エラー・警告メッセージ

### 権限エラー
```
このページへのアクセス権限がありません。
管理者に画面権限の設定を確認してください。
```

### 保存エラー
```
保存に失敗しました。
入力内容を確認のうえ、もう一度お試しください。
解決しない場合はサポートまでお問い合わせください。
```

### セッションタイムアウト
```
セッションの有効期限が切れました。
再度ログインしてください。
```
