# LINE公式アカウント メッセージテンプレート

---

## 1. 友だち追加時のウェルカムメッセージ

```
BizFlo公式アカウントへようこそ！

BizFloは、顧客管理・案件管理・会計・請求書をまとめて管理できるオールインワン業務管理システムです。

このLINEアカウントでは、以下のサポートを行っています。

・導入や操作に関するご質問
・お見積り・プランのご相談
・不具合のご報告

お気軽にメッセージをお送りください。
担当者が確認次第、ご返信いたします。

▼ 操作マニュアルはこちら
https://docs.bizflo27.jp
```

---

## 2. 問い合わせ受付の自動返信

```
お問い合わせありがとうございます。
メッセージを受け付けました。

内容を確認のうえ、担当者より順次ご返信いたします。
通常、営業日1日以内にご対応しております。

お急ぎの場合は、メッセージに「急ぎ」とご記載ください。
優先的に対応いたします。
```

---

## 3. 営業時間外の自動応答

```
お問い合わせありがとうございます。

現在、営業時間外のため、翌営業日に確認・ご返信いたします。

【営業時間】平日 10:00〜17:00
（土日祝・年末年始を除く）

操作方法については、マニュアルサイトもご活用ください。
https://docs.bizflo27.jp
```

---

## 4. 導入検討中の方への返信テンプレート

```
お問い合わせいただきありがとうございます。

BizFloにご興味をお持ちいただき、ありがとうございます。
ご質問やご要望に合わせて、最適なプランをご提案させていただきます。

以下の情報をいただけますと、よりスムーズにご案内できます。

・会社名（または個人名）
・利用予定の人数
・特に使いたい機能（顧客管理、請求書、会計など）

デモ画面のご案内も可能ですので、お気軽にお申し付けください。
```

---

## 5. 不具合報告への返信テンプレート

```
ご報告ありがとうございます。

不具合の内容を確認いたします。
詳細な状況を把握するため、以下の情報をお送りいただけますでしょうか。

・発生した画面名
・操作の手順
・エラーメッセージ（表示されている場合）
・スクリーンショット（可能であれば）

確認でき次第、ご連絡いたします。
ご不便をおかけして申し訳ございません。
```

---

## 6. 対応完了の報告

```
ご連絡いただいた件について、対応が完了いたしました。

{対応内容の概要}

お手数ですが、ご確認をお願いいたします。
他にご不明点がございましたら、お気軽にお問い合わせください。
```
