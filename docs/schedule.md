# スケジュール管理ガイド（BizFlo）

> **対象読者**: 全ユーザー
> **所要時間**: 10〜15分

!!! tip "このページの目的"
    BizFlo の「スケジュール管理」機能を使って、予定の登録・確認・共有を行う方法を説明します。
    顧客・案件と紐付けたスケジュール管理で、業務の見通しを立てやすくなります。

---

## 1. カレンダー画面

**目的**: 日・週・月単位で予定を一覧表示し、スケジュールを把握するため。

ダッシュボード（ホーム画面）にカレンダーが表示されています。

- **月表示**: 1ヶ月の予定を俯瞰
- **週表示**: 1週間の詳細スケジュール
- **日表示**: 1日のタイムライン

予定をクリックすると、詳細を確認・編集できます。

---

## 2. 予定の登録

**目的**: 打ち合わせ、訪問、会議などの予定を登録するため。

### 新しい予定の作成

1. カレンダー上で日時をクリック、または **予定追加** ボタンをクリック
2. 以下を入力

| 項目 | 説明 | 必須 |
|------|------|------|
| **日付** | 予定の日付 | 必須 |
| **開始時刻** | 開始時間 | 必須 |
| **所要時間** | 予定の長さ | 任意 |
| **スケジュール種別** | 訪問、会議、テレアポなど | 任意 |
| **顧客** | 関連する顧客 | 任意 |
| **案件** | 関連する案件 | 任意 |
| **担当者** | 自分＋他のメンバー（複数選択可） | 必須 |
| **連絡方法** | 電話、メール、対面など | 任意 |
| **詳細** | 予定の内容メモ | 任意 |

3. **保存** をクリック

### 複数担当者の設定

1つの予定に複数の担当者をアサインできます。アサインされたメンバー全員のカレンダーに予定が表示されます。

---

## 3. スケジュール種別の設定

**目的**: 予定の分類を会社に合わせてカスタマイズするため。

### 種別の管理

1. **設定 → スケジュール設定** をクリック
2. スケジュール種別の一覧が表示されます
3. 各種別に以下を設定
   - **種別名**（例：訪問、テレアポ、社内会議、テレワーク）
   - **カテゴリ**（分類用）
   - **色**（カレンダー表示色）
   - **表示順序**

### デフォルトの種別例

- 訪問
- 電話
- Web会議
- 社内会議
- テレワーク
- 外出
- 休暇

---

## 4. Google Calendar連携

**目的**: GoogleカレンダーのイベントをBizFloで表示するため。

### 連携の設定

以下のいずれかから連携できます（ユーザーごとの個人設定です）。

- **ユーザー設定** → Google Calendar連携セクション
- **会社設定 → 外部連携設定** タブ → Google Calendar連携セクション

1. **Googleアカウントを連携** ボタンをクリック
2. Googleアカウントでログインして権限を許可
3. 連携が完了すると、Googleカレンダーの予定がBizFloのカレンダーに表示されます

### Googleイベントの表示

- Googleカレンダーの予定は **青色（Googleブランドカラー）** で表示されます
- 日・週・月の全ビューに対応
- Googleイベントはドラッグ・リサイズ不可（読み取り専用）

### Googleイベントの詳細確認

Googleカレンダーの予定をクリックすると、専用の詳細モーダルが表示されます。

- **イベント名** / **日時**
- **場所**（設定されている場合）
- **説明**（設定されている場合）
- **Googleカレンダーで開く** ボタン（自分のイベントの場合のみ）

!!! info "読み取り専用"
    Google Calendar連携は読み取り専用です。BizFlo側でGoogleカレンダーの予定を編集することはできません。

### オンライン予約との連携

Google Calendar連携中は、オンライン予約のスロット計算にもGoogleカレンダーの予定が考慮されます。Googleカレンダーに予定がある時間帯は予約枠として表示されず、ダブルブッキングを防止します。

### 連携の解除

ユーザー設定または会社設定から **連携解除** をクリックすると、連携が解除されます。

## 5. LINE通知との連携

スケジュールに関連する以下のLINE通知が利用できます。

### 朝のまとめ通知

毎朝9:00に、今日の予定がLINEで自動送信されます。

### 10分前リマインダー

予定の10分前にLINEでリマインダー通知が届きます。

通知内容:
- スケジュール種別
- 開始時刻
- 顧客名
- 詳細の概要

!!! info "通知の設定"
    LINE通知は **設定 → ユーザー設定** からON/OFFを切り替えられます。
    スケジュールリマインダーは個別にON/OFFを設定できます。
    詳しくは [LINE連携ガイド](line.md) を参照してください。

---

## 6. 勤務種別管理

**目的**: メンバーの勤務状態を管理し、稼働分析に活用するため。

スケジュール種別のうち、勤務に関するものは **生産性分析** の稼働時間集計に使用されます。

- 設定した勤務種別ごとに稼働時間が自動集計
- ユーザー別・期間別の稼働サマリーを確認可能

詳しくは [分析機能ガイド](analysis.md) を参照してください。

---

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| 予定が表示されない | カレンダーの表示期間を確認してください |
| 他のメンバーの予定が見えない | 担当者フィルタの設定を確認してください |
| Google Calendar連携ができない | ブラウザのポップアップブロックを解除し、再度連携してください |
| リマインダーが届かない | LINE通知設定とスケジュールリマインダー設定を確認してください |
