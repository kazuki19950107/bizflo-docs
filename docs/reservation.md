# 予約管理ガイド（BizFlo）

> **対象読者**: 営業担当者、管理者
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「予約管理」機能を使って、オンライン予約の受付・管理を行う方法を説明します。
    公開予約フォームを顧客に共有することで、日程調整の手間を大幅に削減できます。

---

## 1. 予約管理の全体像

予約管理機能では、以下のワークフローで予約を受け付けます。

1. **管理者**: 予約枠（スロット設定）を作成
2. **管理者**: 公開予約URLを顧客に共有
3. **顧客**: カレンダーから日時を選択して予約
4. **システム**: 予約確認メールを双方に自動送信
5. **管理者**: ダッシュボードで予約を確認・管理

予約はBizFloのカレンダー（スケジュール）にも自動的に登録されます。

---

## 2. スロット設定（予約枠の作成）

**目的**: 予約可能な時間枠のルールを定義するため。

### 新しいスロット設定の作成

1. **設定 → 予約管理** をクリック
2. **新規作成** ボタンをクリック
3. 以下を設定

| 設定項目 | 説明 | 例 |
|---------|------|-----|
| **設定名** | 予約枠の名前 | 30分無料相談 |
| **スラグ** | URL用の識別子（任意） | free-30min |
| **予約可能日** | 受付する曜日 | 月〜金 |
| **予約可能時間** | 開始・終了時刻 | 9:00〜18:00 |
| **予約枠の長さ** | 1回の予約時間 | 30分 / 60分 / 90分 等 |
| **前後のバッファ** | 予約前後の余裕時間 | 前5分、後5分 |
| **予約受付終了** | 何時間前まで受付するか | 24時間前まで |
| **予約可能期間** | 何日先まで公開するか | 14日先まで |

4. **保存** をクリック

!!! tip "複数のスロット設定"
    目的に応じて複数のスロット設定を作成できます。
    例: 「30分面談」「1時間相談」「2時間ワークショップ」

### 予約URLの取得

スロット設定を作成すると、公開予約URLが生成されます。

- URL形式: `/reservation/{ユーザーID}/{スラグまたは設定ID}`
- URLをコピーして、Webサイト・メール署名・SNSなどに掲載できます

---

## 3. フォーム設定

**目的**: 予約フォームの表示内容をカスタマイズするため。

予約設定画面の **フォーム設定** タブで以下を設定できます。

- **フォームタイトル**: 予約フォームのヘッダーテキスト
- **説明文**: フォーム上部に表示される案内文
- **追加項目**: 電話番号・備考欄の表示/非表示

### フォームの入力項目

| 項目 | 必須/任意 | 設定 |
|------|---------|------|
| 会社名 | 必須 | 常に表示 |
| お名前 | 必須 | 常に表示 |
| メールアドレス | 必須 | 常に表示 |
| 電話番号 | 任意 | ON/OFF切り替え可能 |
| 備考 | 任意 | ON/OFF切り替え可能 |

---

## 4. 通知設定

**目的**: 予約通知の受信先やオンライン会議URLを設定するため。

予約設定画面の **通知設定** タブで以下を設定できます。

- **通知メールアドレス**: 予約通知を受信するメールアドレス
- **会議URL**: デフォルトのオンライン会議URL（Zoom、Teams等）

設定した会議URLは、予約確認メールに自動で含まれます。

---

## 5. 顧客側の予約フロー

顧客が予約URLにアクセスすると、以下の手順で予約が完了します。

### Step 1: 日時の選択

1. カレンダーが表示され、予約可能な日が緑色でハイライトされます
2. 日付をクリックすると、その日の空き時間枠が一覧表示されます
3. 希望の時間枠をクリック

### Step 2: 情報の入力

1. 会社名、お名前、メールアドレスを入力
2. 電話番号・備考（設定で有効な場合）を入力
3. **予約する** をクリック

### Step 3: 予約完了

1. 予約完了メッセージが表示されます
2. 顧客にメールで確認が届きます（キャンセルリンク付き）
3. 管理者にもメールで通知が届きます

---

## 6. 予約の管理

### 予約一覧

予約管理画面で、すべての予約を確認できます。

- **ステータス絞り込み**: 全件 / 確認済み / キャンセル済み
- **スロット設定絞り込み**: 特定の予約枠タイプのみ表示
- **サマリー表示**: 合計件数、確認済み件数、キャンセル件数

### 予約の編集

1. 予約一覧から対象の予約をクリック
2. 以下を変更可能
   - 日時の変更（空き状況を自動チェック）
   - 会議URLの変更
   - 顧客情報の更新
   - 対応詳細の更新
   - 予約時間の変更
3. **保存** をクリック

### 予約のキャンセル

**管理者からのキャンセル:**

1. 予約一覧から対象の予約をクリック
2. **キャンセル** ボタンをクリック
3. キャンセル理由を入力（任意）
4. 顧客にキャンセル通知メールが送信されます

**顧客からのキャンセル:**

- 予約確認メールのキャンセルリンクから操作
- キャンセル理由を入力して確定
- 管理者に通知メールが送信されます

!!! info "キャンセルの制限"
    予約受付終了時間を過ぎた予約はキャンセルできません。
    過去の予約もキャンセルできません。

---

## 7. メール通知

予約管理では、以下のタイミングでメールが自動送信されます。

| タイミング | 送信先 | 内容 |
|-----------|--------|------|
| 予約確定時 | 顧客 | 予約詳細、会議URL、キャンセルリンク |
| 予約確定時 | 管理者 | 予約詳細、顧客情報 |
| キャンセル時（顧客） | 管理者 | キャンセル通知、理由 |
| キャンセル時（管理者） | 顧客 | キャンセルのお知らせ |
| 予約変更時 | 双方 | 変更後の予約詳細 |

---

## 8. 他機能との連携

### カレンダー連携

- 予約はスケジュール（カレンダー）に自動登録されます
- スケジュール種別「オンライン予約」として表示
- ダッシュボードのカレンダービューで確認可能

### 顧客管理連携

- 予約時に顧客情報が自動で作成/更新されます
- 新規顧客は「見込み客」ステータスで登録
- 既存顧客は名前＋メールアドレスで自動マッチング

### 空き時間の自動計算

- 既存のスケジュール（カレンダー予定）と予約の両方を考慮
- バッファ時間を含めた空き状況の判定
- 二重予約を自動防止

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| 予約URLが開けない | スロット設定が有効（アクティブ）になっているか確認してください |
| 空き枠が表示されない | 予約可能日・時間の設定、予約受付終了時間、予約可能期間を確認してください |
| メールが届かない | 通知設定のメールアドレスが正しいか確認してください |
| 顧客がキャンセルできない | 予約受付終了時間の設定を確認してください |
