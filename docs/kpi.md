# KPI管理ガイド（BizFlo）

> **対象読者**: 営業担当者、管理者、経営層
> **所要時間**: 20〜30分

!!! tip "このページの目的"
    BizFlo の「KPI管理」機能を使って、営業活動や成果を数値で可視化する方法を説明します。
    **目標値と実績値の比較**により、進捗を正しく把握し、改善につなげられます。

---

## 1. KPIダッシュボードの概要

**目的**: 営業活動や経営指標を一目で把握するため。

1. 左メニューから **経営管理 → KPI** をクリック
2. 登録済みのKPIがカード形式で表示されます
   - **KPI名・実績値・目標値・達成率（%）**
   - **達成度プログレスバー**
   - **予測ステータス**（期間内の場合）
3. 各KPIカードをクリックすると、ユーザー別の内訳グラフが表示されます

---

## 2. KPIの新規作成

**目的**: 自社独自の指標を追加・管理するため。

1. KPIダッシュボード右上の **＋ KPI追加** をクリック
2. 以下を設定

| 項目 | 説明 |
|------|------|
| **KPI名** | 指標の名前（例：月間売上、商談件数） |
| **対象パラメータ** | 計測対象を選択（下記参照） |
| **単位** | 件 / 時間 / ポイント / 円 / % |
| **集計期間** | 日次 / 週次 / 月次 / 四半期 / 年次 |
| **グラフタイプ** | 棒グラフ / 折れ線グラフ / 円グラフ |
| **グラフサイズ** | 全幅 / 1/2 / 1/3 / 2/3 |
| **表示カラー** | 6色から選択（青・緑・赤・紫・オレンジ・ティール） |

3. **ユーザー別の目標値** を入力（一括設定も可能）
4. **保存** をクリック

### 対象パラメータの種類

| パラメータ | 説明 |
|-----------|------|
| **イベントタイプ** | スケジュールの活動タイプ別に件数または時間を集計 |
| **ポイント** | タスク完了時の重みポイントを集計（案件のレート係数を乗算） |
| **売上（受注日ベース）** | 受注確定済みの請求書の売上を受注日で集計 |
| **売上（見込含む）** | 受注確定 + 見込み案件の売上を含めて集計 |
| **売上（請求日ベース）** | 請求書発行日を基準に売上を集計 |
| **粗利（受注日ベース）** | 売上 − 原価を受注日で集計 |
| **粗利（見込含む）** | 見込み案件を含めた粗利を集計 |
| **利益率** | 粗利 ÷ 売上 × 100 |
| **利益率（見込含む）** | 見込み案件を含めた利益率 |

!!! tip "売上ステータスの分類"
    - **確定**: 受注・請求書発行・納品完了・領収書発行・入金済み
    - **見込み**: 下書き・見積提出

---

## 3. 期間フィルター

**目的**: 期間を切り替えて、短期・中期・長期の進捗を把握するため。

ダッシュボード上部のクイックボタンで期間を切り替えられます。

| ボタン | 期間 |
|--------|------|
| **今月** | 当月1日〜月末 |
| **月初〜現在** | 当月1日〜今日 |
| **先月** | 前月1日〜前月末 |
| **今年** | 1月1日〜12月31日 |
| **来月** | 翌月1日〜翌月末 |
| **再来月** | 翌々月1日〜翌々月末 |

カスタム期間を指定することも可能です（日付ピッカーで開始日・終了日を選択）。

!!! tip "目標値の自動調整"
    選択した期間に応じて、目標値が自動的にスケーリングされます。
    例：月次KPIで15日間だけ選択した場合、目標値は約半分に調整されます。

## 4. 予測機能

**目的**: 現在のペースで期間終了時にどの程度達成できるかを予測するため。

KPIダッシュボードでは、各KPIに対して自動的に達成予測が計算されます。

### 予測の仕組み

予測は **現在の日次ペースを線形に延長** して算出されます。

- **日次ペース** = 実績値 ÷ 経過日数
- **予測達成値** = 実績値 + （日次ペース × 残り日数）
- **必要日次ペース** = （目標値 − 実績値） ÷ 残り日数

### 予測ステータス

| ステータス | 表示 | 条件 |
|-----------|------|------|
| **達成ペース** | 緑 | 予測値が目標値以上 |
| **やや遅れ** | 黄 | 日次ペースが必要ペースの80%以上 |
| **未達ペース** | 赤 | 日次ペースが必要ペースの80%未満 |

### 予測の表示内容

- **サマリーカード**: 「予測: ○○円（残○日）」とステータスバッジを表示
- **グラフ上**: 予測値を破線で表示（ステータスに応じて色分け）
- **プログレスバー**: 現在値 → 予測値 → 目標値の3段階で表示

!!! note "予測の注意点"
    予測は過去の実績を元にした線形の推定値です。季節性やトレンドの変化は考慮されません。
    目標値が設定されていない場合、または期間の残り日数が0の場合は予測が表示されません。

## 5. KPIの管理

### 表示順の変更

1. ダッシュボード上部の **表示順変更** をクリック
2. ドラッグ＆ドロップでKPIの並び順を変更
3. **保存** をクリック

### KPIの非表示・再表示

1. ダッシュボード上部の **非表示KPI管理** をクリック
2. 非表示にしたKPIの一覧が表示されます
3. 各KPIに対して以下の操作が可能
   - **再表示**: ダッシュボードに戻す
   - **編集**: KPIの設定を変更
   - **削除**: KPIを完全に削除

### KPIの編集・削除

- 各KPIカードの **編集** ボタンから設定を変更
- **削除** ボタンでKPIを削除（確認ダイアログが表示されます）

!!! warning "削除の注意"
    KPIを削除すると、設定されたユーザー別目標値もすべて削除されます。

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| KPIが表示されない | 権限設定を確認してください（経営管理画面へのアクセス権が必要です） |
| 実績値が合わない | 対象パラメータと期間フィルターの設定を確認してください |
| 予測が表示されない | 目標値が設定されているか、期間に残り日数があるか確認してください |
| グラフが正しく表示されない | ブラウザを更新してください |
