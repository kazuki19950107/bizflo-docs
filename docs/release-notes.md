## 2026年2月

### 2026-02-14
- **AI分析アシスタント大幅改善**
  - チャットUIを全面リニューアル（フルスクリーンレイアウト、Markdown対応）
  - 日付解析を大幅拡充（M/D形式、日付範囲指定、Xヶ月後/前、再来週など）
  - インテント解析のキーワードを大幅拡充（見積、帳票、納品、受発注、経費等に対応）
  - 予定ごとに顧客・案件のコンテキストを個別表示するように改善
  - OEMファビコンをAIアバターに使用
  - ページヘッダーを他画面と統一

- **顧客テキスト解析・名刺OCR解析の精度大幅改善**

- **全画面レスポンシブ対応・モバイルUI完全最適化**

- **セキュリティ管理機能の全体適用**
  - 画面権限管理を全ユーザーに開放
