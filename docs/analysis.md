# 分析機能ガイド(BizFlo)

> **対象読者**: 管理者、経営層、営業リーダー
> **所要時間**: 25〜40分

!!! tip "このページの目的"
    BizFlo の「分析機能」を使って、売上・顧客・生産性などを多角的に分析する方法を説明します。
    データに基づいた経営判断を行い、ビジネスの成長を加速させましょう。

---

## 1. 売上分析ダッシュボード

**目的**: 売上の推移、顧客別売上、商品別売上を可視化し、売上向上の施策を検討するため。

1. 左メニューから **分析 → 売上分析** をクリック
2. 以下のグラフ・データが表示されます
   - **月別売上推移**（過去12ヶ月）
   - **顧客別売上ランキング**（売上上位10社）
   - **商品別売上構成**（売上割合の円グラフ）
   - **粗利率の推移**（売上総利益率）
   - **営業利益の予測**（固定費を考慮）

### フィルタリング機能

- **期間指定**: 過去3ヶ月 / 6ヶ月 / 12ヶ月 / カスタム
- **担当者絞り込み**: 特定の営業担当者のデータのみ表示
- **案件ステータス**: 受注済み / 見込み含む

!!! tip "売上分析の活用ポイント"
    - 売上が伸びている顧客には追加提案を実施
    - 売上が減少している顧客には早めにフォローアップ
    - 粗利率が低い商品は価格戦略を見直す

---

## 2. 生産性分析

**目的**: チームや個人の稼働状況を分析し、業務効率を改善するため。

1. 左メニューから **分析 → 生産性分析** をクリック
2. 以下の指標が表示されます
   - **作業時間の内訳**（案件別・タスク別）
   - **担当者別の稼働時間**
   - **タスク完了率**（期限内完了率）
   - **案件あたりの平均工数**
   - **勤怠サマリー**（日次稼働詳細）

!!! example "生産性改善の施策例"
    - 長時間タスクは分割して管理
    - 稼働が少ないメンバーに業務を再配分
    - 定型タスクは自動化やテンプレート化を検討
    - 案件別の作業分析で工数見積もりの精度を向上

---

## 3. AI分析アシスタント

**目的**: AIが自動的にデータを分析し、経営判断に役立つインサイトを提供するため。

1. 左メニューから **分析 → AI分析** をクリック
2. 質問を入力（例：「今月の売上状況を教えて」）
3. AIが以下を自動実行
   - データの収集と集計
   - トレンドの分析
   - 改善提案の生成
4. 分析結果が自然言語で返答されます

### AIが対応できる質問例

- **売上関連**: 「今月の売上は先月と比べてどうですか?」
- **顧客関連**: 「新規顧客の獲得状況は?」
- **案件関連**: 「遅延している案件はありますか?」
- **KPI関連**: 「目標達成率を教えてください」
- **予測**: 「来月の売上予測はいくらですか?」

!!! tip "AI分析の活用ポイント"
    - 週次ミーティングの前に状況を確認
    - 経営会議の資料作成に活用
    - 過去のデータと比較して傾向を把握

---

## 4. 顧客分析

**目的**: 顧客をセグメント化し、効果的なマーケティング・営業戦略を立てるため。

1. AI分析アシスタントで顧客に関する質問をする
2. 以下の分析が可能です
   - **顧客セグメント分析**（VIP / regular / potential / inactive）
   - **顧客別売上集計**
   - **紹介ルート分析**（どの経路から顧客を獲得しているか）
   - **新規顧客の獲得状況**

!!! example "顧客分析の活用例"
    - VIP顧客には特別プランを提案
    - inactive（非アクティブ）顧客にはリマインドメールを送信
    - 紹介ルートの効果測定でマーケティング施策を最適化
    - 新規顧客の獲得ペースを把握

---

## 5. 売上サイクル分析

**目的**: 営業案件の進捗状況を可視化し、売上予測を把握するため。

1. 売上分析ダッシュボードで売上サイクルデータを確認
2. 以下の情報が表示されます
   - **見積 → 受注までの平均日数**
   - **受注 → 請求までの平均日数**
   - **請求 → 入金までの平均日数**
   - 各ステージ間の所要時間

!!! tip "売上サイクル分析の活用ポイント"
    - 商談期間が長い場合は営業プロセスを見直す
    - 入金までの期間が長い場合は与信管理や請求フローを改善
    - 売上サイクルの短縮で資金繰りを改善

---

## 6. AIチャット履歴のエクスポート

**目的**: AI分析アシスタントとの会話履歴を保存し、報告書に利用するため。

1. AI分析アシスタント画面で **エクスポート** をクリック
2. 出力形式を選択（TXT / CSV / JSON）
3. ダウンロードして記録として保存

!!! tip "活用のポイント"
    - 定期的な分析内容を記録として保存
    - 経営会議での質問と回答を議事録として活用
    - 過去の分析結果と比較

---

## トラブルシュート

- データが表示されない
  → 期間設定を確認し、該当期間にデータが存在するか確認してください
- グラフが正しく表示されない
  → ブラウザをリロードしてください。改善しない場合はキャッシュをクリア
- AI分析が応答しない
  → 質問を具体的に変更してください（例：「売上」→「今月の売上」）
- AIチャット履歴のエクスポートができない
  → ブラウザのポップアップブロックを解除してください
