# 契約管理ガイド(BizFlo)

> **対象読者**: 営業担当者、法務担当者、管理者
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「契約管理」機能を使って、契約書の作成・管理・更新通知を行う方法を説明します。
    案件や顧客と紐付けて管理することで、契約の抜け漏れを防ぎます。

---

## 1. 契約書の新規作成

**目的**: 顧客との契約内容をシステムに登録し、一元管理するため。

1. 左メニューから **契約管理 → 契約一覧** をクリック
2. 右上の **＋ 新規契約追加** をクリック
3. 以下を入力
   - **契約名**（例：「システム開発業務委託契約」）
   - **顧客選択**（顧客管理と紐付け）
   - **案件選択**（案件管理と紐付け、任意）
   - **契約金額**
   - **契約開始日・終了日**
   - **自動更新**（有効/無効）
   - **契約タイプ**（請負 / 委任 / 売買 / ライセンス 等）
   - **契約書ファイル**（PDFアップロード）
4. **保存** をクリック

!!! tip "便利機能"
    - 契約書テンプレートを利用すると、入力項目を自動入力できます
    - 案件に紐付けると、案件詳細から契約情報を確認可能

---

## 2. 契約書テンプレートの設定

**目的**: よく使う契約書フォーマットをテンプレート化し、作成を効率化するため。

1. **契約管理 → テンプレート設定** をクリック
2. **＋ 新規テンプレート作成** をクリック
3. 以下を設定
   - テンプレート名（例：「標準業務委託契約」）
   - 契約タイプ
   - 標準契約期間（12ヶ月 等）
   - 契約書フォーマット（Word / PDF）をアップロード
   - 自動入力項目の設定（顧客名・契約日 等）
4. **保存** をクリック

### テンプレートの活用

- 新規契約作成時にテンプレートを選択すると、基本情報が自動入力
- 顧客名や契約日などの変数が自動置換されます

---

## 3. 契約更新の管理

**目的**: 契約の更新漏れを防ぎ、適切なタイミングで更新手続きを行うため。

### 契約更新の手続き

1. **契約一覧** から更新対象の契約をクリック
2. 契約終了日を確認し、更新が必要か判断
3. 契約情報を編集して新しい契約開始日・終了日を入力
4. **保存** をクリック

!!! note "今後の機能追加予定"
    以下の機能を追加予定です:
    - 契約終了日の自動通知（90日前・30日前・7日前）
    - 自動更新設定（期限到来時に自動延長）

---

## 4. 電子署名機能

**目的**: 契約書にオンラインで署名し、契約締結を完結するため。

### 電子署名の手順

1. 契約書を作成後、顧客にメールで送信
2. 顧客がLINK URLから契約書を確認
3. 画面上で署名を記入（Canvas署名）
4. 署名完了後、Word形式でダウンロード可能
5. 双方に署名完了通知メールが送信されます

!!! tip "電子署名の活用"
    - 対面での契約締結が不要になり、業務効率化
    - 署名データはS3に安全に保存
    - 署名完了後も編集前のデータを保持

## 6. 契約の検索・一覧管理

**目的**: 登録済みの契約を効率的に確認し、期限や金額を把握するため。

1. **契約一覧** をクリック
2. 検索条件を入力
   - 顧客名
   - 契約タイプ
   - ステータス（有効 / 終了 等）
   - 期間（契約開始日 / 終了日）
   - 契約金額
3. 絞り込み結果から詳細を確認

!!! example "よくある使い方"
    - 「ステータス: 更新待ち」で絞り込んで、更新手続きが必要な契約を確認
    - 「契約終了日: 今月」で絞り込んで、今月終了する契約を抽出
    - 顧客別に契約一覧を表示して、契約状況を確認

## トラブルシュート

- 契約が保存できない
  → 必須項目（契約名・顧客・契約開始日・終了日）が入力されているか確認してください
- 契約書ファイルがアップロードできない
  → ファイルサイズが10MB以下か、PDF形式か確認してください
- 電子署名が保存されない
  → ブラウザのポップアップブロックを解除してください
- 外部電子契約サービス連携が使えない
  → 現在開発中の機能です。リリースをお待ちください
