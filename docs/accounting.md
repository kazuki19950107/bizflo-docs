# 会計管理ガイド（BizFlo）

> **対象読者**: 経理担当者、管理者、経営層  
> **所要時間**: 30〜45分

!!! tip "このページの目的"
    BizFlo の「会計管理」機能を使って、売上・経費・仕訳・帳票を管理する方法を説明します。  
    日々の取引を正しく入力することで、**損益計算書（PL）・貸借対照表（BS）** などの財務データを自動作成できます。  

---

## 1. 仕訳の入力

**目的**: すべての取引を複式簿記形式で記録し、会計処理の基盤を作るため。

1. 左メニューから **会計管理 → 仕訳入力** をクリック
2. **＋ 新規仕訳** をクリック
3. 以下を入力
   - 日付（取引日）
   - 勘定科目（借方・貸方）
   - 金額
   - 補助科目（取引先名など、必要に応じて）
   - 摘要（取引の内容）
   - 証憑番号（領収書番号など）
4. **保存** をクリック

!!! tip "便利機能"
    - 仕訳の複製機能で定期的な取引を素早く入力できます
    - 過去の仕訳を検索して参照可能
    - 総勘定元帳から科目別の取引履歴を確認できます

!!! example "活用例"
    - 売上計上（借方：売掛金 / 貸方：売上高）
    - 経費計上（借方：通信費 / 貸方：現金）  

---

## 2. 売上情報の登録（請求書連携）

**目的**: 請求書と会計を連動させ、売上を自動で反映するため。  

1. **受注管理 → 請求書** を開く  
2. 請求書を発行すると、自動的に「売上高」として仕訳が作成される  
3. 必要に応じて仕訳を修正可能  

!!! tip "おすすめ"
    請求書の作成を営業担当に任せ、経理は自動仕訳を確認・承認するフローが効率的です。  

---

## 3. 経費の登録

**目的**: 日々の経費を入力し、損益計算に反映させるため。

1. **会計管理 → 仕訳入力** をクリック
2. 経費の仕訳を入力
   - 借方：経費科目（交通費、消耗品費、通信費など）
   - 貸方：現金 または クレジットカード
   - 金額・日付・摘要を入力
3. **保存** をクリック

!!! tip "AI仕訳入力の活用"
    領収書をアップロードすると、AIが自動的に日付・金額・科目を読み取って仕訳を提案します。詳しくは「AI仕訳入力機能」を参照してください。  

---

## 4. 試算表の確認

**目的**: 月次や期間ごとの勘定科目残高を確認し、決算前の帳簿チェックを行うため。

1. **会計管理 → 試算表** をクリック
2. 以下を設定
   - 会計期間（または開始日・終了日）
   - 残高0の科目も表示するか
3. **表示** をクリック
4. 試算表に以下が表示されます
   - 勘定科目コード・科目名
   - 期首残高
   - 借方合計 / 貸方合計
   - 期末残高

!!! tip "試算表の活用方法"
    - 月次決算時に貸借のバランスを確認
    - 異常な残高がないかチェック
    - 決算前の修正仕訳の判断材料として利用

---

## 5. 補助元帳の確認

**目的**: 特定の勘定科目について、取引先や案件ごとの詳細な取引履歴を確認するため。

1. **会計管理 → 補助元帳** をクリック
2. 以下を設定
   - 勘定科目を選択（売掛金、買掛金など）
   - 補助科目を選択（取引先名など）
   - 期間を指定
3. **表示** をクリック
4. 補助元帳に以下が表示されます
   - 取引日・伝票番号
   - 摘要（取引内容）
   - 借方金額 / 貸方金額
   - 残高

!!! example "活用例"
    - 売掛金補助元帳で顧客別の未回収額を確認
    - 買掛金補助元帳で仕入先別の支払残高を管理
    - プロジェクト別の収支を補助科目で追跡

---

## 6. AI仕訳入力機能

**目的**: 領収書や請求書の画像からAIが情報を自動抽出し、仕訳を提案するため。経理作業を大幅に効率化できます。

1. **会計管理 → AI仕訳入力** をクリック
2. **領収書・請求書の画像をアップロード**（JPG、PNG、PDF対応）
   - 複数ファイル一括アップロード可能（最大20ファイル）
3. AIが自動的に以下を抽出・提案
   - 日付
   - 金額
   - 勘定科目（旅費交通費、通信費、消耗品費、接待交際費など）
   - 支払方法（クレジットカード、銀行振込、現金など）
4. 内容を確認し、必要に応じて修正
5. **全て登録** をクリックして仕訳を一括保存

!!! tip "AI仕訳のポイント"
    - Google Cloud Vision APIで高精度なOCR処理
    - 複数の領収書をまとめてアップロードして一括処理
    - 不明な項目は手動で修正可能

---

## 7. 帳票の出力

**目的**: 財務状況を把握し、外部提出用の帳票を出力するため。

1. **会計管理 → 帳票** をクリック
2. 出力したい帳票を選択
   - **損益計算書（PL）**
   - **貸借対照表（BS）**
   - **キャッシュフロー計算書（CF）**
   - **試算表**
   - **仕訳帳 / 総勘定元帳**
   - **補助元帳**
3. 期間を指定して **出力（CSV / Excel / PDF）** をクリック

!!! warning "注意"
    帳票は登録済みの仕訳データをもとに作成されます。
    入力漏れがあると正しい数値が出力されません。

---

## 8. 会計期間管理

**目的**: 年度や月次の会計期間を設定し、期間ごとに帳簿を管理するため。

1. **会計管理 → 会計期間** をクリック
2. **＋ 新規期間追加** をクリック
3. 以下を設定
   - 期間名（例：2025年度、2025年4月期）
   - 開始日・終了日
   - 期の種類（年次 / 月次 / 四半期）
4. **保存** をクリック

!!! tip "会計期間の管理ポイント"
    - 期間を正しく設定することで、試算表や帳票が期間別に作成可能
    - 期間を閉じると、その期間の仕訳は編集不可になり、誤修正を防止
    - 次期繰越処理で期末残高を自動的に次期に引き継ぎ

---

## 9. 会計データのエクスポート

**目的**: 税理士や外部会計ソフトとデータを連携するため。

1. **会計管理 → データ出力** をクリック
2. 出力形式を選択（CSV / Excel）
3. 保存して税理士に共有、または弥生会計などのソフトにインポート

!!! tip "エクスポート機能の活用"
    - 定期的にバックアップとしてエクスポート
    - 税理士との連携時に会計データを共有
    - 他システムへの移行時にデータを活用

---

## トラブルシュート

- 金額が合わない  
  → 借方・貸方の入力ミスを確認してください  
- 請求書が売上に反映されない  
  → 請求書ステータスが「発行済み」になっているか確認  
- 帳票が空欄で出力される  
  → 指定期間に仕訳が登録されているか確認してください
