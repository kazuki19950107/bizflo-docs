# タスク管理ガイド(BizFlo)

> **対象読者**: 全ユーザー
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「タスク管理」機能を使って、個人やチームのタスクを管理する方法を説明します。
    案件に紐付けたタスク管理で、プロジェクトの進捗を可視化できます。

---

## 1. タスクの新規作成

**目的**: 実行すべき作業をタスクとして登録し、進捗管理を行うため。

1. 左メニューから **タスク一覧** をクリック
2. 右上の **＋ タスク追加** をクリック
3. 以下を入力
   - **タスク名**（例：「顧客A社への見積書作成」）
   - **担当者**（自分または他のメンバー）
   - **期限**（完了予定日）
   - **優先度**（高 / 中 / 低）
   - **案件紐付け**（任意：関連する案件を選択）
   - **説明**（タスクの詳細内容）
4. **保存** をクリック

!!! tip "便利機能"
    - 案件に紐付けると、案件詳細画面でタスク一覧を確認できます
    - 目標工数と時給を設定すると、案件の原価管理が可能です

---

## 2. AI自動タスク生成機能

**目的**: プロジェクト概要からAIが自動的にタスクを細分化して提案するため。

1. 案件詳細画面を開く
2. **AI タスク生成** ボタンをクリック
3. プロジェクト概要を入力（例：「ECサイトのリニューアル」）
4. AIが自動的にタスクを提案
   - 例: 「要件定義」「デザイン作成」「開発」「テスト」「リリース」
5. 提案されたタスクを確認し、必要に応じて修正
6. **一括登録** をクリック

!!! tip "活用ポイント"
    - プロジェクト立ち上げ時の初期タスク作成が大幅に効率化
    - 過去のプロジェクトパターンを学習し、提案精度が向上

---

## 3. タスクの進捗管理

**目的**: タスクの進捗状況をリアルタイムで更新し、チーム全体で共有するため。

### 進捗率の更新

1. **タスク一覧** から対象タスクをクリック
2. **進捗率** を入力（0%〜100%）
3. **保存** をクリック

### タスクの完了

1. タスク一覧で対象タスクの **完了** ボタンをクリック
2. 進捗率が自動的に100%になり、完了日時が記録されます

!!! example "進捗管理のベストプラクティス"
    - 毎日終業時に進捗率を更新する習慣をつける
    - 週次ミーティングでタスク一覧を確認し、遅延タスクを早期発見

---

## 4. カンバンボード（Kanban）表示

**目的**: タスクの状態を視覚的に管理し、ワークフローを可視化するため。

1. **タスク一覧** 画面で右上の **カンバン表示** をクリック
2. タスクが以下のカラムに分類表示されます
   - **未着手**: まだ開始していないタスク
   - **進行中**: 作業中のタスク
   - **レビュー中**: 確認待ちのタスク
   - **完了**: 完了済みタスク
3. タスクをドラッグ&ドロップで移動すると、ステータスが自動更新

!!! tip "カンバン活用のポイント"
    - チーム全員で画面共有しながらの朝会に最適
    - 進行中のタスクが多すぎる場合は、優先順位を見直す

---

## 5. タスクの検索・絞り込み

**目的**: 大量のタスクから必要なものを素早く見つけるため。

1. **タスク一覧** をクリック
2. 検索条件を設定
   - **担当者**（自分 / 特定のメンバー / 全員）
   - **期限**（今日まで / 今週まで / 期限切れ）
   - **優先度**（高 / 中 / 低）
   - **ステータス**（未着手 / 進行中 / 完了）
   - **案件**（特定の案件に紐付いたタスクのみ）
3. 絞り込み結果が一覧表示されます

!!! example "よくある使い方"
    - 「期限が今日まで」で絞り込んで、緊急タスクを確認
    - 「担当者: 自分」で絞り込んで、自分の作業を一覧化
    - 「ステータス: 進行中」で絞り込んで、現在進行形の作業を確認

---

## 6. チームメンバーへのタスク割り当て

**目的**: タスクを適切な担当者に割り当て、チーム全体で効率的に作業するため。

1. タスク作成時または編集時に **担当者** を選択
2. 複数の担当者を設定可能（共同作業の場合）
3. 担当者には自動的に通知が送信されます

!!! tip "タスク割り当てのポイント"
    - スキルや稼働状況を考慮して担当者を選ぶ
    - タスクの説明欄に期待する成果物を明記する
    - 定期的に進捗を確認し、必要に応じてサポート

---

## 7. カスタム進捗ステータスの設定

**目的**: プロジェクトに合わせた独自の進捗状態を定義するため。

1. 管理画面から **タスクステータス設定** をクリック
2. ステータス名と進捗率を設定
   - 例: 「設計中」50%、「実装中」70%、「テスト中」90%
3. カンバンボードで設定したステータスが列として表示されます

!!! note "今後の機能追加予定"
    以下の機能を追加予定です:
    - タスク期限通知（期限3日前・当日・超過時）
    - タスクの依存関係管理UI
    - 定期タスクの自動生成

---

## トラブルシュート

- タスクが保存できない
  → 必須項目（タスク名・担当者・期限）が入力されているか確認してください
- カンバンボードでドラッグできない
  → ブラウザをリロードしてください。改善しない場合は管理者に連絡
- AI タスク生成が動作しない
  → プロジェクト概要を具体的に記述してください
