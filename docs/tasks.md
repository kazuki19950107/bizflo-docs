# タスク管理ガイド（BizFlo）

> **対象読者**: 全ユーザー
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「タスク管理」機能を使って、個人やチームのタスクを管理する方法を説明します。
    案件に紐付けたタスク管理で、プロジェクトの進捗を可視化できます。

---

## 1. タスクの新規作成

**目的**: 実行すべき作業をタスクとして登録し、進捗管理を行うため。

1. 案件詳細画面で **タスク追加** をクリック
2. 以下を入力
   - **タスク名**（例：「顧客A社への見積書作成」）
   - **担当者**（複数選択可能）
   - **期限**（完了予定日）
   - **開始日**（任意）
   - **目標工数**（時間）
   - **ウェイト**（タスクの重み付け、デフォルト1）
   - **備考**（タスクの詳細内容）
3. **保存** をクリック

!!! tip "便利機能"
    - 案件に紐付けると、案件詳細画面でタスク一覧を確認できます
    - 目標工数と時給を設定すると、案件の原価管理が可能です

---

## 2. AI自動タスク生成機能

**目的**: プロジェクト概要からAIが自動的にタスクを細分化して提案するため。

1. 案件詳細画面を開く
2. **AI タスク生成** ボタンをクリック
3. プロジェクト概要を入力（例：「ECサイトのリニューアル」）
4. AIが自動的にタスクを提案
   - 例: 「要件定義」「デザイン作成」「開発」「テスト」「リリース」
5. 提案されたタスクを確認し、必要に応じて修正
6. **一括登録** をクリック

!!! tip "活用ポイント"
    - プロジェクト立ち上げ時の初期タスク作成が大幅に効率化
    - プロジェクト概要をできるだけ具体的に書くと精度が向上します

---

## 3. タスクの進捗管理

**目的**: タスクの進捗状況をリアルタイムで更新し、チーム全体で共有するため。

### 進捗率の更新

1. **タスク一覧** から対象タスクをクリック
2. **進捗率** を入力（0%〜100%）
3. **保存** をクリック

### タスクの完了

1. タスクの進捗率を **100%** に設定すると、完了日時が自動記録されます
2. 100%未満に戻すと、完了日時がクリアされます

!!! example "進捗管理のベストプラクティス"
    - 毎日終業時に進捗率を更新する習慣をつける
    - 週次ミーティングでタスク一覧を確認し、遅延タスクを早期発見

---

## 4. カンバンボード表示

**目的**: タスクの状態を視覚的に管理し、ワークフローを可視化するため。

1. **タスク一覧** 画面で **カンバン表示** に切り替え
2. タスクが進捗ステータスごとのカラムに分類表示されます
   - デフォルト: **未着手**（0%）/ **進行中**（50%）/ **完了**（100%）
   - カスタムステータスを設定するとカラムが追加されます
3. タスクをドラッグ&ドロップで移動すると、進捗率が自動更新

### 並び替え

- **リスト表示**: タスクの表示順をドラッグで変更可能
- **カンバン表示**: カラム内の並び順、カラム間の移動の両方に対応

!!! tip "カンバン活用のポイント"
    - チーム全員で画面共有しながらの朝会に最適
    - 進行中のタスクが多すぎる場合は、優先順位を見直す

---

## 5. カスタム進捗ステータスの設定

**目的**: プロジェクトに合わせた独自の進捗状態を定義するため。

1. **設定 → タスクステータス設定** をクリック
2. 各ステータスに以下を設定
   - **ステータス名**（例：「設計中」「実装中」「テスト中」）
   - **進捗率**（0〜100の数値、カンバンのカラム位置を決定）
   - **カラー**（カンバンカラムの色）
   - **表示順序**
3. カンバンボードに設定したステータスがカラムとして表示されます

### デフォルトに戻す

カスタムステータスをリセットして、デフォルトの3ステータス（未着手/進行中/完了）に戻すことができます。

!!! warning "注意"
    - 同じ進捗率のステータスは作成できません
    - デフォルトステータスは削除できません
    - ステータスを削除すると、そのステータスのタスクは「進行中」（50%）に移動されます

---

## 6. 定期タスク（定期業務）

**目的**: 毎週・毎月繰り返す業務を自動でスケジューリングするため。

### 定期タスクの作成

1. **定期業務** 画面を開く
2. **新規作成** をクリック
3. 以下を入力
   - **タスク名**（例：「月次報告書の作成」）
   - **頻度**: 毎日 / 毎週 / 毎月
   - **曜日**（毎週の場合）または **日付**（毎月の場合）
   - **開始日**: スケジュールの基準日
   - **表示開始日数**: 期限のX日前から表示
   - **顧客・案件**（任意）
   - **メモ**
4. **保存** をクリック

### 定期タスクの管理

- **ダッシュボード表示**: ホーム画面に期限が近い定期タスクが表示されます
- **完了操作**: 当該サイクルの完了ボタンをクリック → 次回サイクルに自動移行
- **完了取り消し**: 誤って完了した場合は取り消し可能
- **履歴確認**: 過去の完了履歴を確認できます

### ステータス表示

| ステータス | 説明 |
|-----------|------|
| **完了** | 現サイクルで完了済み |
| **期限超過** | 期限を過ぎて未完了 |
| **まもなく期限** | 期限7日以内 |
| **予定** | 期限まで7日以上 |

!!! tip "定期タスクの活用例"
    - 毎月の請求書発行作業
    - 週次の進捗報告
    - 日次の在庫確認

---

## 7. タスクの検索・絞り込み

**目的**: 大量のタスクから必要なものを素早く見つけるため。

1. **タスク一覧** をクリック
2. 検索条件を設定
   - **担当者**（自分 / 特定のメンバー / 全員）
   - **案件**（特定の案件に紐付いたタスクのみ）
   - **ステータス**（進捗率でフィルタ）
3. 絞り込み結果が一覧表示されます

---

## 8. LINE通知との連携

タスクの期限通知は、LINE連携の「朝のまとめ通知」で受け取ることができます。

- 毎朝9時に、担当タスクの一覧がLINEで通知されます
- タスクの通知表示ON/OFFを個別に設定可能

詳しくは [LINE連携ガイド](line.md) を参照してください。

---

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| タスクが保存できない | タスク名が入力されているか確認してください |
| カンバンでドラッグできない | ブラウザをリロードしてください |
| AIタスク生成が動作しない | プロジェクト概要を具体的に記述してください |
| 定期タスクが表示されない | 表示開始日数の設定と開始日を確認してください |
