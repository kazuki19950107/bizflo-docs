# LINE連携ガイド(BizFlo)

> **対象読者**: 営業担当者、全ユーザー
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「LINE連携」機能を使って、外出先からLINEで業務を行う方法を説明します。
    スマホのLINEから予定確認、顧客検索、帳票登録、音声メモなどが可能になります。

!!! info "前提条件"
    LINE連携機能を使用するには、管理者によるLINE公式アカウントの設定が完了している必要があります。

---

## 1. LINEとBizFloアカウントの連携

**目的**: 自分のLINEアカウントとBizFloアカウントを紐付けるため。

### 初回連携の手順

1. 会社のLINE公式アカウントを友だち追加
2. LINEで自分のBizFloアカウント名（ログインID）を送信
3. システムがアカウント名を認識して自動的に連携完了
4. 連携完了のメッセージが届きます

!!! tip "連携のポイント"
    - 一度連携すれば、以降はLINEから直接機能を利用できます
    - アカウント名はBizFloのログイン画面で使用しているIDです
    - 連携がうまくいかない場合は、アカウント名が正しいか確認してください

---

## 2. LINEからできる主な機能

**目的**: 外出先でもスマホから業務を行うため。

### 2.1 予定の確認・登録

LINEで「予定」「予定管理」「スケジュール」と送信すると、予定を確認・登録できます。

- 今日の予定一覧
- 時間・場所・顧客名
- 予定の新規登録

### 2.2 顧客情報の検索

LINEで「顧客検索」と送信すると、顧客検索画面が開きます。

- 名前で検索
- 電話番号で検索
- 会社名で検索
- 検索結果から顧客詳細を確認

### 2.3 空き時間の確認

LINEで「空き時間」と送信すると、担当者の空き予定を確認できます。

- 自分の空き時間
- 他のメンバーの空き時間
- 日程調整に活用

### 2.4 その他の機能

以下の機能もLINEから利用できます:

- **帳票登録**: 領収書や経費精算を登録
- **案件管理**: 案件の確認・一覧表示
- **対応履歴追加**: 顧客との対応内容を記録

---

## 3. 音声メモ機能

**目的**: 音声で素早くメモを記録するため。

### 使い方

1. LINEで「メモ」または「クイックメモ」と送信
2. 音声メッセージを送信
3. AIが自動で文字起こし
4. テキストメモとして保存されます

### 期限付きメモ

音声メッセージの最初に日付(yyyymmdd形式)を言うと、期限付きメモとして登録されます。

!!! example "音声メモの例"
    - 「20251020 顧客Aに見積書送付」→ 10月20日期限のメモ
    - 「明日の会議資料を準備」→ 通常のメモ

---

## 4. 名刺OCR機能

**目的**: 名刺をLINEで送信するだけで顧客情報を登録するため。

### 名刺登録の手順

1. LINEで「名刺登録」と送信
2. 名刺の表面を撮影して送信
3. 「裏面はありますか?」と聞かれるので、ある場合は裏面も送信
4. 「他の名刺はありますか?」と聞かれる
5. 続ける場合は「はい」、終了する場合は「いいえ」
6. AIが自動で以下を抽出
   - 氏名
   - 会社名
   - 電話番号
   - メールアドレス
   - 住所
7. 自動的に顧客情報として登録完了

!!! tip "名刺OCR活用のポイント"
    - 最大10枚まで連続で登録可能
    - 展示会やイベントで大量の名刺を効率的に登録
    - 外出先から即座に情報登録
    - 手入力の手間とミスを削減

## 5. LINEからの通知機能

**目的**: 重要な情報をLINEで自動通知するため。

### 自動通知されるイベント

- **朝の予定サマリー**: 毎朝8時に今日の予定を自動送信

!!! note "今後の機能追加予定"

    - タスク期限通知

## 6. LINEで使えるコマンド一覧

**目的**: LINEから素早く必要な機能にアクセスするため。

以下のコマンドをLINEに送信することで、各機能を利用できます:

| コマンド | 機能 |
|---------|------|
| （アカウント名を送信） | BizFloアカウントと連携（初回のみ） |
| `予定` / `予定管理` / `スケジュール` | 今日の予定を表示・登録 |
| `顧客検索` | 顧客を検索 |
| `空き時間` / `空き予定` | 空き予定を確認 |
| `帳票登録` | 領収書や経費を登録 |
| `案件管理` / `案件一覧` | 案件を確認 |
| `対応履歴追加` | 顧客対応を記録 |
| `メモ` / `クイックメモ` | 音声メモを記録 |
| `名刺登録` | 名刺から顧客情報を登録 |
| `ヘルプ` / `使い方` | 使い方を表示 |

---

## トラブルシュート

- LINE連携ができない
  → BizFloのアカウント名（ログインID）が正しいか確認してください
  → それでもうまくいかない場合は管理者に連絡してください
- コマンドを送っても反応しない
  → 最初にアカウント名を送信してアカウント連携を完了させてください
- 画面が開かない
  → LINEアプリを最新版にアップデートしてください
- 通知が届かない
  → LINEの通知設定を確認してください
