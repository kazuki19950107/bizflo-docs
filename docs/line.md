# LINE連携ガイド（BizFlo）

> **対象読者**: 営業担当者、全ユーザー
> **所要時間**: 15〜25分

!!! tip "このページの目的"
    BizFlo の「LINE連携」機能を使って、外出先からLINEで業務を行う方法を説明します。
    スマホのLINEから予定確認、顧客検索、帳票登録、音声メモなどが可能になります。

!!! info "前提条件"
    LINE連携機能を使用するには、管理者によるLINE公式アカウントの設定が完了している必要があります。

---

## 1. LINEとBizFloアカウントの連携

**目的**: 自分のLINEアカウントとBizFloアカウントを紐付けるため。

### 初回連携の手順

1. 会社のLINE公式アカウントを友だち追加
2. LINEで自分のBizFloアカウント名（ログインID）を送信
3. システムがアカウント名を認識して自動的に連携完了
4. 連携完了のメッセージが届きます

!!! tip "連携のポイント"
    - 一度連携すれば、以降はLINEから直接機能を利用できます
    - アカウント名はBizFloのログイン画面で使用しているIDです

---

## 2. 予定の確認・登録

LINEから予定の管理ができます。

### コマンド

| コマンド | 動作 |
|---------|------|
| `予定登録` / `予定入力` / `スケジュール` | スケジュール登録画面を開く |
| `予定管理` / `スケジュール管理` | メニュー表示（登録/確認/空き時間） |
| `予定確認` / `空き予定` / `空き時間` | 空き時間確認画面を開く |
| `今日の空き` | 今日の空き時間をテキストで表示 |
| `明日の空き` | 明日の空き時間をテキストで表示 |

空き時間の表示は、9:00〜18:00の範囲で1時間以上の空きスロットを一覧で返します。

---

## 3. 顧客管理

### 顧客検索

`顧客検索` と送信すると、顧客検索画面が開きます。名前・電話番号・会社名で検索できます。

### 顧客登録

`顧客登録` と送信すると、登録方法を選択できます。

- **名刺スキャン**: 名刺のOCR登録（後述）
- **手動入力**: 手動入力画面を開く

### 対応履歴の追加

`対応履歴追加` と送信すると、顧客名の入力を求められます。

1. 顧客名を入力
2. 該当する顧客の候補が表示される
3. 顧客を選択すると、対応履歴入力画面が開く

---

## 4. 名刺OCR機能

**目的**: 名刺をLINEで送信するだけで顧客情報を自動登録するため。

### 名刺登録の手順

1. LINEで `顧客登録` → `名刺スキャン` を選択
2. 名刺の**表面**を撮影して送信
3. 「裏面はありますか？」と聞かれるので、ある場合は裏面も送信
4. 「他の名刺はありますか？」と聞かれる
5. **はい** → 次の名刺の表面を送信（ステップ2に戻る）
6. **いいえ** → OCR処理開始

### 自動抽出される項目

- 氏名、氏名カナ
- 会社名、会社名カナ
- 電話番号、FAX
- メールアドレス
- 住所
- 役職、部署
- HP（ホームページ）
- インボイス番号

!!! tip "名刺OCR活用のポイント"
    - 最大**10枚**まで連続で登録可能（10枚で自動的にOCR処理開始）
    - 展示会やイベントで大量の名刺を効率的に登録
    - 裏面のスキャンも対応（両面情報を統合して解析）

---

## 5. 帳票登録（レシートOCR）

**目的**: 領収書やレシートをLINEで送信して、会計データを登録するため。

### 登録手順

1. `帳票登録` と送信
2. レシートや領収書の画像を送信（複数枚OK）
3. `完了` と送信するとAI解析が開始
4. AIが自動で以下を抽出・分類
   - 金額、日付、取引先
   - 勘定科目の推定

---

## 6. 案件・タスク管理

LINEから案件とタスクの確認・管理ができます。

| コマンド | 動作 |
|---------|------|
| `案件一覧` / `案件リスト` | 案件一覧画面を開く |
| `案件管理` / `プロジェクト管理` | メニュー表示（案件一覧/タスク一覧/タスク追加） |

案件画面からはタスクの確認・追加・ステータス更新が可能です。

---

## 7. メモ・Todo機能

### テキストメモ

コマンド以外のテキストを送信すると、自動的にTodoメモとして保存されます。

- 先頭に `yyyymmdd` 形式の日付を入れると、期限付きメモになります
- 例: `20260220 顧客Aに見積書送付` → 2月20日期限のメモ

### 音声メモ

音声メッセージを送信すると、AIが自動で文字起こしして保存します。

- OpenAI Whisper APIによる高精度な文字起こし
- 先頭に日付(`yyyymmdd`)を話すと期限付きメモになります

### クイックメモ

`メモ` / `クイックメモ` と送信すると、メモ・Todo管理画面が開きます。

---

## 8. ファイル管理（一時ファイル）

コマンドに関係なく画像やPDFを送信すると、「一時ファイル」として保存されます。

- 後からPC画面で顧客や案件に紐付けることができます
- メモ画面から一時ファイルの一覧を確認・管理できます

---

## 9. 通知機能

### 朝のまとめ通知

毎朝 **9:00** に、以下の情報がLINEで自動送信されます。

- **今日の予定**: スケジュール一覧
- **Todoリスト**: 未完了のメモ
- **担当タスク**: 通知ONのタスク一覧
- **今日の豆知識**: AIが生成するビジネス雑学

!!! info "通知の設定"
    - **設定画面** でLINE通知のON/OFFを切り替えられます
    - 通知を受け取る**曜日**を選択できます（デフォルト：平日のみ）

### スケジュールリマインダー

予定の **10分前** にLINEでリマインダー通知が届きます。

通知内容:

- スケジュール種別
- 開始時刻
- 顧客名
- 詳細（先頭50文字）

!!! info "リマインダーの設定"
    - **設定画面** でスケジュールリマインダーのON/OFFを個別に設定できます
    - LINE通知自体がOFFの場合、リマインダーも送信されません

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| LINE連携ができない | BizFloのアカウント名（ログインID）が正しいか確認してください |
| コマンドを送っても反応しない | アカウント連携が完了しているか確認してください |
| 名刺OCRの精度が低い | 明るい場所でピントを合わせて撮影してください |
| 通知が届かない | 設定画面でLINE通知がONか、通知曜日が正しいか確認してください |
| リマインダーが届かない | スケジュールリマインダー設定がONか確認してください |
| 画面が開かない | LINEアプリを最新版にアップデートしてください |
