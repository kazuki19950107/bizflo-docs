# 受発注管理ガイド（BizFlo）

> **対象読者**: 営業担当者、購買担当者、経理担当者
> **所要時間**: 20〜40分

!!! tip "このページの目的"
    BizFlo の受発注管理の全体像を説明します。
    受注（売上）は請求書管理、発注（仕入）は仕入管理で管理され、案件・顧客・会計と自動で連動します。

---

## 1. 受発注管理の全体像

BizFloでは、受注と発注をそれぞれ以下のモジュールで管理します。

| 区分 | 管理画面 | 詳細ガイド |
|------|---------|-----------|
| **受注（売上）** | 帳票管理 → 請求書一覧 | [請求書管理ガイド](invoice.md) |
| **発注（仕入）** | 帳票管理 → 仕入一覧 | [請求書管理ガイド - 仕入管理](invoice.md#9-仕入管理発注) |

---

## 2. 受注の流れ（売上）

**目的**: 顧客からの注文内容をシステムに記録し、請求や売上計上に反映させるため。

### ステータスの流れ

```
下書き → 見積提出 → 受注 → 請求書発行 → 納品完了 → 領収書発行 → 入金済み
```

### 操作手順

1. **帳票管理 → 請求書一覧** から **＋ 新規作成** をクリック
2. 以下を入力
   - 顧客（顧客管理と紐付け）
   - 案件（案件管理と紐付け、任意）
   - 請求日・支払期日
   - 明細情報（品名・数量・単価・税率）
3. **保存** をクリック
4. ステータスを進めることで、見積書→受注書→請求書→領収書と帳票を切り替え

### 会計への自動反映

- **請求書発行** ステータスにすると: 売上仕訳が自動作成（借方: 売掛金 / 貸方: 売上高）
- **入金済み** にすると: 入金仕訳が自動作成（借方: 普通預金 / 貸方: 売掛金）

!!! tip "帳票の出力"
    請求書詳細画面の「帳票出力」からExcel形式の帳票ファイルをダウンロードできます。
    ステータスに応じた帳票（見積書・受注書・請求書・領収書）が出力されます。

---

## 3. 発注の流れ（仕入）

**目的**: 仕入先への発注を管理し、仕入原価や在庫を正しく反映するため。

### ステータスの流れ

```
発注済 → 納品済 → 支払済
        → キャンセル（いつでも可能）
```

### 操作手順

1. **帳票管理 → 仕入一覧** から **新規作成** をクリック
2. 以下を入力
   - 仕入先（顧客マスタから選択）
   - 発注日・納品予定日・支払期日
   - 件名
   - 明細情報（品名・数量・単価・税率）
   - 商品マスタから選択すると単価が自動入力されます
3. **保存** をクリック

### ステータスごとの自動処理

| ステータス | 自動処理 |
|-----------|---------|
| **発注済** | — |
| **納品済** | 在庫数の自動増加 + 仕入仕訳の自動作成（借方: 仕入高 / 貸方: 買掛金） |
| **支払済** | 支払仕訳の自動作成（借方: 買掛金 / 貸方: 普通預金） |
| **キャンセル** | 在庫数の自動戻し |

!!! note "在庫管理"
    商品マスタで「在庫管理」を有効にしている商品のみ、仕入ステータスに連動して在庫数が自動更新されます。

---

## 4. 定期請求

**目的**: 毎月定額で発生する請求を自動化するため。

サブスクリプションや保守料など、定期的に発生する請求は自動化できます。

1. **帳票管理 → 定期請求設定** をクリック
2. 顧客・案件・請求内容・請求サイクル（毎月・四半期・年次）を設定
3. 設定した日付に自動で請求書が作成されます

---

## 5. 受発注の検索・一覧管理

**目的**: 登録済みの受注・発注を効率的に確認し、進捗や残高を把握するため。

### 請求書一覧（受注）

1. **帳票管理 → 請求書一覧** をクリック
2. 検索条件（顧客名・案件名・ステータス・期間）で絞り込み
3. 一覧から詳細を確認

### 仕入一覧（発注）

1. **帳票管理 → 仕入一覧** をクリック
2. 検索条件で絞り込み
3. 一覧から詳細を確認

!!! example "よくある使い方"
    - 月末に「発行済み」で未入金の請求書を抽出して入金督促
    - 支払期日が迫っている仕入伝票を一覧化して支払準備
    - 「見積提出」状態の案件をフォローアップ

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| 商品が選べない | 商品マスタに登録されているか確認してください |
| 請求書の金額が合わない | 単価・税率の設定を確認してください |
| 売上が会計に反映されない | 請求書ステータスが「請求書発行」以降になっているか確認してください |
| 仕入の在庫が更新されない | 商品マスタで在庫管理がONか確認してください |
| 定期請求が作成されない | 定期請求設定の開始日・終了日と請求日を確認してください |
