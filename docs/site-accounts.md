# サイトアカウント管理ガイド（BizFlo）

> **対象読者**: 管理者
> **所要時間**: 5〜10分

!!! tip "このページの目的"
    BizFlo の「サイトアカウント管理」機能を使って、外部サービスのログイン情報を安全に一元管理する方法を説明します。
    チーム内でアカウント情報を共有し、パスワードの管理負荷を軽減できます。

---

## 1. サイトアカウント管理とは

業務で利用する外部サービス（クラウドツール、SNS、管理画面など）のログイン情報を、BizFlo上で暗号化して一元管理する機能です。

### 主な特徴

- **暗号化保存**: パスワードは暗号化されて保存されます
- **ロール制限**: アカウント情報の閲覧をロールで制限できます
- **カテゴリ分類**: サービスをカテゴリで整理できます
- **ファビコン自動取得**: URLからサイトのアイコンを自動取得します

---

## 2. アカウントの登録

**目的**: 外部サービスのログイン情報を安全に保存するため。

1. 左メニューから **サイトアカウント管理** をクリック
2. **新規登録** をクリック
3. 以下を入力

| 項目 | 説明 |
|------|------|
| **タイトル** | サービス名（例：Google Workspace、Slack） |
| **カテゴリ** | 分類カテゴリ |
| **閲覧権限** | 閲覧可能なロール（管理者、マネージャー、スタッフ、パート） |
| **ログインURL** | ログインページのURL |
| **ログインID** | アカウントのID/メールアドレス |
| **パスワード** | パスワード |
| **カスタム情報** | その他のメモ情報（複数追加可能） |

4. **保存** をクリック

### 複数ログイン情報

1つのサービスに対して複数のログイン情報を登録できます。例えば、管理者アカウントと一般アカウントを分けて管理できます。

---

## 3. カテゴリの管理

**目的**: サービスをカテゴリごとに整理するため。

1. サイトアカウント管理画面で **カテゴリ管理** をクリック
2. カテゴリ名を入力して追加

### カテゴリの例

- 業務ツール（Slack、Teams、Zoom等）
- クラウドサービス（AWS、Google Cloud等）
- SNS（Twitter、Facebook等）
- 管理画面（サーバー、ドメイン等）

---

## 4. 閲覧権限の設定

**目的**: 機密性の高いアカウント情報へのアクセスを制限するため。

各アカウントに対して、閲覧可能なロールを設定できます。

| ロール | 説明 |
|--------|------|
| **管理者** | 全アカウント閲覧可能 |
| **マネージャー** | 許可されたアカウントのみ |
| **スタッフ** | 許可されたアカウントのみ |
| **パート** | 許可されたアカウントのみ |

!!! tip "権限設定のポイント"
    - 機密性の高いアカウント（決済系、サーバー管理等）は管理者のみに制限
    - チーム全員が使うツール（チャット、メール等）は全ロールに開放

---

## 5. アカウント情報の確認

1. サイトアカウント管理画面でアカウント一覧を表示
2. 検索ボックスでサービス名やカテゴリで絞り込み
3. アカウントをクリックして詳細を表示
4. パスワードは表示ボタンで確認（暗号化されて保存）

---

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| アカウントが表示されない | 自分のロールに閲覧権限があるか確認してください |
| ファビコンが表示されない | URLが正しいか確認してください。一部のサイトはファビコン取得に対応していません |
| パスワードが表示できない | ブラウザのJavaScriptが有効か確認してください |
