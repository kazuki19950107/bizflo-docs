# 請求書管理ガイド(BizFlo)

> **対象読者**: 営業担当者、経理担当者、管理者
> **所要時間**: 20〜35分

!!! tip "このページの目的"
    BizFlo の「請求書管理」機能を使って、見積書・発注書・請求書・納品書などの帳票を作成・管理する方法を説明します。
    案件や顧客と紐付けて管理することで、営業から経理まで一元的に情報を共有できます。

---

## 1. 請求書の新規作成

**目的**: 顧客への請求内容をシステムに登録し、帳票を発行するため。

1. 左メニューから **帳票管理 → 請求書一覧** をクリック
2. 右上の **＋ 新規作成** をクリック
3. 以下を入力
   - **顧客選択**（顧客管理と紐付け）
   - **案件選択**（案件管理と紐付け、任意）
   - **請求日・支払期日**
   - **件名**（請求内容の説明）
   - **明細情報**
     - 品名・数量・単価
     - 税率（10% / 8% / 非課税）
4. **保存** をクリック

!!! tip "便利機能"
    - 商品マスタから品目を選択すると、単価が自動入力されます
    - 過去の請求書をコピーして新規作成も可能
    - 案件に紐付けると、売上が自動で会計管理に反映されます

---

## 2. 請求書のステータス管理

**目的**: 請求書の発行状況を可視化し、入金管理を行うため。

請求書は以下のステータスで管理されます:

- **下書き (data_created)**: 作成中（編集可能）
- **見積提出 (quoted)**: 見積書として提出済み
- **受注 (order)**: 受注確定
- **請求書発行 (invoice)**: 請求書発行済み
- **納品完了 (delivered)**: 納品完了
- **領収書発行 (receipt)**: 領収書発行済み
- **入金済み (paid)**: 支払い完了

### ステータスの変更方法

1. **請求書一覧** から対象の請求書をクリック
2. 右上の **ステータス変更** をクリック
3. 新しいステータスを選択
4. **保存** をクリック

!!! tip "ステータス履歴"
    ステータス変更履歴は自動で記録され、いつ誰が変更したか確認できます。

---

## 3. 請求書テンプレートの設定

**目的**: 自社のデザインに合わせた請求書フォーマットを作成するため。

1. **帳票管理 → テンプレート設定** をクリック
2. **＋ 新規テンプレート作成** をクリック
3. 以下を設定
   - テンプレート名（例：標準請求書、簡易見積書）
   - ヘッダー・フッター情報
   - ロゴ画像のアップロード
   - 項目の表示/非表示
   - フォントやレイアウトの調整
4. **保存** をクリック

!!! example "活用例"
    - 顧客向けと社内用でテンプレートを分ける
    - 業種や案件タイプ別にテンプレートを使い分ける

---

## 4. 定期請求書の設定

**目的**: 毎月定額で発生する請求を自動化するため（サブスクリプション、保守料など）。

1. **帳票管理 → 定期請求設定** をクリック
2. **＋ 新規定期請求追加** をクリック
3. 以下を設定
   - 顧客・案件
   - 請求内容（品名・金額）
   - 請求サイクル（毎月・四半期・年次）
   - 開始日・終了日
   - 請求日（例：毎月末日）
4. **保存** をクリック

!!! tip "自動発行のポイント"
    - 設定した日付に自動で請求書が作成されます
    - メール送信も自動化できます（設定が必要）
    - 定期請求の一覧から個別に停止・編集が可能

---

## 5. 請求書の送付

**目的**: 作成した請求書を顧客に送付するため。

### Excel形式で出力して送付

1. 請求書詳細画面を開く
2. 右上の **帳票出力** をクリック
3. Excel形式の帳票ファイルをダウンロード
4. メールやチャットで顧客に送付

!!! note "出力形式について"
    現在はExcel形式での出力に対応しています。PDFでの送付が必要な場合は、Excelファイルを開いてPDFとして保存してください。

### 定期請求のメール自動送信

定期請求書では、メール自動送信を設定できます:
1. 定期請求設定で送信先メールアドレスを設定
2. メール件名テンプレートを設定
3. 請求書作成時に自動でメール送信されます

---

## 6. 請求書と会計の連携

**目的**: 請求書データを会計管理に自動反映させ、売上を正確に計上するため。

請求書を **発行済み** ステータスにすると、以下が自動で実行されます:

- 売上仕訳の自動作成（借方: 売掛金 / 貸方: 売上高）
- 総勘定元帳への反映
- 損益計算書（PL）への売上計上

入金処理を行うと:

- 売掛金の消込処理（借方: 普通預金 / 貸方: 売掛金）
- 補助元帳への反映

!!! warning "注意"
    請求書を削除すると、自動作成された仕訳も削除されます。修正する場合は、請求書を編集してください。

---

## 7. 請求書の検索・一覧管理

**目的**: 登録済みの請求書を効率的に確認し、入金状況を把握するため。

1. **請求書一覧** をクリック
2. 検索条件を入力
   - 顧客名
   - 案件名
   - ステータス（発行済み / 入金済み など）
   - 期間（請求日 / 支払期日）
3. 絞り込み結果から詳細を確認

!!! example "よくある使い方"
    - 月末に「発行済み」で未入金の請求書を抽出
    - 支払期日が過ぎた請求書を一覧化して督促

---

## 8. 見積書・受注書・領収書の作成

**目的**: 請求書以外の帳票も同じシステムで一元管理するため。

BizFloでは以下の帳票も請求書と同じ操作で作成できます:

- **見積書 (quoted)**: 顧客への見積提示
- **受注書 (order)**: 顧客からの注文確認
- **請求書 (invoice)**: 代金請求
- **領収書 (receipt)**: 入金確認

### 作成方法

1. **帳票管理** から新規作成をクリック
2. 必要事項を入力
3. ステータスを選択して保存
4. 該当するステータスの帳票として出力

!!! tip "ステータス変更で帳票を切り替え"
    - 同じ帳票データでステータスを変更することで、見積書→受注書→請求書→領収書と段階的に進められます
    - データはそのまま引き継がれ、ステータスに応じた帳票が出力されます

---

## 9. 仕入管理（発注）

**目的**: 仕入先への発注を管理し、在庫・会計と連携するため。

### 仕入伝票の作成

1. **帳票管理 → 仕入一覧** をクリック
2. **新規作成** をクリック
3. 以下を入力
   - **仕入先**（顧客マスタから選択）
   - **発注日・納品予定日・支払期日**
   - **件名**
   - **明細情報**（品名・数量・単価・税率）
   - 商品マスタから選択すると単価が自動入力されます
4. **保存** をクリック

### 仕入ステータスの管理

| ステータス | 説明 | 自動処理 |
|-----------|------|---------|
| **発注済** | 発注完了 | — |
| **納品済** | 商品を受領 | 在庫数の自動増加 + 仕入仕訳の自動作成 |
| **支払済** | 支払い完了 | 支払仕訳の自動作成 |
| **キャンセル** | 発注取消 | 在庫数の自動戻し |

### 会計連携

- **納品済**にすると: 仕入計上の仕訳が自動作成（借方: 仕入高 / 貸方: 買掛金）
- **支払済**にすると: 支払の仕訳が自動作成（借方: 買掛金 / 貸方: 普通預金）

### 在庫管理

商品マスタで「在庫管理」を有効にしている商品は、仕入ステータスに連動して在庫数が自動更新されます。

---

## トラブルシュート

| 症状 | 対処法 |
|------|--------|
| 請求書が保存できない | 必須項目（顧客・請求日・明細）が入力されているか確認してください |
| 帳票出力がうまくいかない | ブラウザのポップアップブロックを解除してください |
| 会計に反映されない | 請求書のステータスが「発行済み」になっているか確認してください |
| 仕入の在庫が更新されない | 商品マスタで在庫管理がONか確認してください |
