# 運用ガイド（BizFlo）

> **対象読者**: 管理者、システム運用担当者、チームリーダー
> **所要時間**: 随時利用

!!! tip "このページの目的"
    BizFlo を日常的に運用する際に必要となる **管理・効率化・サポート** の方法をまとめています。
    単なる操作だけでなく、「なぜその設定をするのか」「どんなメリットがあるのか」を理解できるよう整理しています。

## 1. ロールと画面権限管理

**目的**: ユーザーごとに利用範囲を制御し、誤操作や情報漏洩を防止するため。

### ユーザーロール

| ロール | 説明 |
|--------|------|
| **管理者** | 全画面にアクセス可能、ユーザー管理・権限設定が可能 |
| **メンバー** | 許可された画面にアクセス可能 |
| **会計閲覧者** | 会計画面の閲覧のみ可能 |

### 画面権限の設定

!!! note "管理者専用メニュー"
    「基本設定」は管理者のみアクセスできます。含まれる項目：会社設定、稼働・勤怠タイプ、権限管理、セキュリティ管理

1. **基本設定 → 権限管理** をクリック
2. 各画面（ホーム・顧客管理・案件管理・取引管理・経営管理・会計管理・契約管理・基本設定）に対して、ロール別のアクセスを許可/拒否
3. **金額情報の表示** をOFFにすると、売上・請求金額がユーザーに表示されなくなります

!!! example "権限設定の例"
    - 営業チーム（メンバー）：ホーム・顧客管理・案件管理・取引管理を許可
    - 経理チーム（会計閲覧者）：会計管理を許可
    - 管理者：全画面にアクセス可能

### ユーザーの非表示設定

産休・育休・長期休暇中のユーザーをスケジュールや勤怠画面から非表示にできます。

1. **管理 → ユーザー管理** からユーザーを選択
2. **表示設定** を「非表示」に変更
3. **非表示理由**（産休、育休など）を入力

!!! tip "非表示の効果"
    非表示にしたユーザーはスケジュール・勤怠の一覧に表示されなくなりますが、アカウント自体は有効なままです。復帰時に再表示に切り替えられます。

## 2. 顧客データ運用ルール

**目的**: 顧客情報を一元管理し、営業・会計・サポートの全機能で活用するため。

- **紹介者紐づけ**: 顧客登録時に「誰から紹介されたか」を残すことで、紹介ルートの効果を分析可能
- **LINE連携**: LINEから顧客対応履歴を自動登録、営業の対応漏れを防止
- **名刺OCR**: 名刺をアップロードするだけで顧客登録が可能、入力ミスや手間を削減
- **テキスト解析**: SNSプロフィールやメール署名から顧客情報を自動抽出

---

## 3. 案件・契約の運用ルール

**目的**: 案件・契約を一貫して管理し、売上・原価・利益を正確に把握するため。

- **案件コピー機能**: 類似案件を素早く複製し、担当者だけ差し替えて再利用
- **契約管理**: 契約書テンプレートのプレースホルダーから電子契約まで一元管理
- **進捗ステータス**: 案件の状態を自社の営業フローに合わせてカスタマイズ
- **外部共有**: 共有リンクを発行して社外のパートナーと案件情報を共有

---

## 4. 帳票・ドキュメント管理

**目的**: 見積書・請求書・納品書などをシステム上で自動生成し、二重入力を防ぐため。

1. 案件・受注データを基に帳票を自動生成
2. 過去帳票をコピーして編集可能
3. Excel形式で帳票を出力

!!! tip "便利ポイント"
    - 帳票テンプレートを事前に整えておくと、統一されたデザインで外部提出可能
    - インボイス番号や銀行口座情報は会社情報から自動反映

## 5. ダッシュボードと分析

**目的**: チームや個人の活動をリアルタイムで可視化し、経営判断に活かすため。

### ダッシュボード機能
- **KPIダッシュボード**: 売上・受注率・活動量をカード形式で表示、予測機能付き
- **パイプライン分析**: 案件ステージ別の金額と件数を可視化
- **売上分析**: 期間別の売上トレンドと構成比を分析
- **生産性分析**: 勤務種別ごとの稼働時間を集計・可視化

### タスク・スケジュール管理
- **タスク一覧**: 担当者別にタスクを管理、Kanbanボードで進捗を可視化
- **カレンダー**: スケジュール管理、Google Calendarと連携可能
- **リマインダー機能**: 10分前にLINE通知、毎朝9時にモーニングメモ配信

## 6. リリースログ管理

**目的**: システムのアップデート情報をユーザーに通知するため。

### 管理者の操作

1. **管理 → リリースログ** をクリック
2. **新規作成** をクリック
3. 以下を入力
   - バージョン番号
   - タイトル・説明
   - 内容（HTML形式で装飾可能）
   - 優先度・カテゴリ
   - リリース日
   - 公開状態
4. **保存** をクリック

### メール通知

リリースログを公開する際に、全ユーザーにメール通知を送信できます。

### ユーザー側の確認

- ユーザーはリリースログ一覧から最新の更新情報を確認できます
- 未読のリリースログがある場合、件数が表示されます
- 確認したリリースログは既読としてマークされます

## 7. LINE通知の運用

**目的**: 外出先でもスマートフォンから業務情報を確認するため。

### 通知の種類

| 通知 | 配信タイミング |
|------|---------------|
| **モーニングメモ** | 毎朝 9:00（当日のスケジュール + TODO + タスク + 豆知識） |
| **スケジュールリマインダー** | 予定の10分前 |

### 通知設定

ユーザーごとに以下を設定できます。

- **LINE通知の受信ON/OFF**
- **受信する曜日の選択**（月〜日で個別に設定）
- **スケジュールリマインダーのON/OFF**

## 8. Google Calendar連携

**目的**: 既存のGoogleカレンダーの予定をBizFloのカレンダーに表示し、予約のダブルブッキングを防止するため。

### 連携方法（ユーザーごとの個人設定）

以下のいずれかから設定できます。

- **ユーザー設定** → Google Calendar連携セクション
- **会社設定（基本設定 → 会社設定）** → **外部連携設定** タブ → Google Calendar連携

1. **Googleアカウントを連携** をクリック
2. Googleの認証画面でアクセスを許可
3. 連携完了後、Googleカレンダーの予定がBizFloのカレンダーに青色で表示されます

### 連携でできること

- カレンダー（日・週・月ビュー）にGoogleの予定を表示
- Googleイベントの詳細確認（場所・説明をモーダルで表示）
- 自分のイベントからGoogleカレンダーへ直接遷移
- オンライン予約のスロット計算にGoogleの予定を自動考慮（ダブルブッキング防止）

!!! note "連携の範囲"
    Google Calendarの予定は**閲覧のみ**です。BizFloからGoogleカレンダーの予定を作成・編集することはできません。

連携を解除する場合は、ユーザー設定または会社設定から **連携解除** をクリックします。

## 9. データのバックアップ

**目的**: 障害や誤操作に備えて、データを復元可能にするため。

1. **会計管理** の各帳票画面からCSVエクスポートが可能
2. 定期的にダウンロードし、安全なストレージに保存

!!! tip "おすすめ運用"
    - 月1回は会計データをCSVエクスポート
    - 税理士との連携時に会計データを共有

## 10. トラブル時の対応

**目的**: 問題が発生した際に迅速に解決するため。

| 症状 | 対処法 |
|------|--------|
| ログインできない | 管理者にパスワードリセットを依頼 |
| 画面表示がおかしい | ブラウザキャッシュをクリア、推奨ブラウザ（Chrome最新版）を利用 |
| 会計数値が合わない | 仕訳の漏れ・重複を確認 |
| メニューが表示されない | 画面権限の設定を管理者に確認 |
| LINE通知が届かない | LINE連携設定と通知曜日の設定を確認 |
