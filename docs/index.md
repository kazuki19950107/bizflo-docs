## BizFloとは？

**BizFlo** は、中小企業・チーム向けの **オールインワン業務管理システム** です。
営業、顧客管理、案件管理、会計、受発注、KPIダッシュボードを一元化し、業務の効率化と情報共有を支援します。

### 主な機能

| 機能 | 説明 |
|------|------|
| **顧客管理** | 紹介者紐づけ、LINE連携、名刺OCR、AIテキスト解析でスピーディに顧客登録 |
| **案件管理** | ステータス管理、ガントチャート、外部共有、ファイル管理、Excelエクスポート |
| **タスク管理** | Kanbanボード、定期タスク、カスタム進捗ステータス |
| **スケジュール管理** | カレンダー、Google Calendar連携、LINEリマインダー |
| **請求書管理** | 見積書・請求書・領収書の作成、定期請求、仕入管理、会計自動連携 |
| **契約管理** | 契約書テンプレート、プレースホルダー自動入力、電子契約 |
| **受発注管理** | 受注・発注を一元管理、帳票の自動作成 |
| **会計管理** | 総勘定元帳、PL・BS・CF自動生成、AI仕訳入力、経営指標ダッシュボード |
| **KPI管理** | 目標と実績の可視化、予測機能、カスタムKPI |
| **分析・AIアシスタント** | 自然言語で業務データを質問、売上分析、生産性分析 |
| **LINE連携** | モーニングメモ、スケジュールリマインダー、名刺OCR、各種LIFF機能 |
| **予約管理** | 予約スロット設定、公開予約フォーム、メール通知、カレンダー連携 |
| **サイトアカウント管理** | 外部サービスのログイン情報を暗号化して一元管理 |
| **運用・管理** | 画面権限管理、リリースログ、ユーザー管理 |

## 導入メリット

- **二重入力をゼロに**
  顧客・案件・会計・帳票が連動しているため、同じ情報を何度も入力する必要がありません。

- **チームの生産性を向上**
  営業・経理・管理部門が同じ情報をリアルタイムに共有できます。

- **経営判断に役立つ分析**
  売上や稼働状況をダッシュボードで即座に確認でき、迅速な意思決定が可能です。

- **スモールスタート可能**
  小規模から始めて、必要に応じて機能を追加していくことができます。
